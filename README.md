# 🔮 AuraMeme

یک ربات **سیگنال و آنالیز امنیتی میم‌کوین** روی شبکه‌ی **Solana / pump.fun**.
میم‌کوین‌های تازه‌ساخت رو لحظه‌ای رصد می‌کنه، از نظر **کلاهبرداری/rug/فریز** آنالیز می‌کنه،
کیف‌پول‌های **تریدر موفق (smart money)** رو ردگیری می‌کنه، امتیاز می‌ده، و
**سیگنال + نقطه ورود و خروج** رو به **تلگرام** و یک **داشبورد وب** می‌فرسته.

> این ابزار فقط **آلارم و آنالیز** می‌ده؛ هیچ‌وقت خودش معامله نمی‌کنه و کلید خصوصی نمی‌گیره.

---

## ⚠️ اول این رو بخون (مهم‌ترین بخش)

می‌خوام صادق باشم تا با توقع غلط ضرر نکنی:

| چیزی که خواستی | واقعیت |
|---|---|
| «تشخیص بده پول فریز نمی‌شه» | ✅ ریسک فریز رو **تشخیص** می‌ده (freeze authority)، ولی **تضمین صفر** هیچ‌رباتی نمی‌تونه بده |
| «همیشه قبل دامپ خروج بده با سود کامل» | ❌ تایمینگ دقیق دامپ غیرممکنه. فقط **قوانین مدیریت ریسک** (پلکان سود + استاپ + تریلینگ + خروج با smart money) می‌ده |
| «سود چندبرابریِ مطمئن» | ❌ بیش از ۹۰٪ میم‌کوین‌ها به صفر می‌رسن. این ابزار **شانس** رو بهتر می‌کنه، نه بیشتر |
| «اینسایدرها رو پیدا کن» | ✅ به‌صورت **heuristic** باندل/اسنایپرها رو تشخیص می‌ده، نه ۱۰۰٪ |

**همیشه فقط با پولی بازی کن که کامل از دستش بدی، زندگی‌ت بهم نمی‌ریزه.**

## این ربات چی‌کار می‌کنه؟

### ۱) آنالیز امنیتی (ضدِ کلاهبرداری) — `src/analysis/score.ts`
- **Freeze authority**: اگه renounce نشده باشه یعنی سازنده می‌تونه توکن‌هاتو **فریز** کنه که نتونی بفروشی → مهم‌ترین نشانه‌ی honeypot. اینجا verdict سقفش **AVOID** می‌شه.
- **Mint authority**: اگه renounce نشده، سازنده می‌تونه بی‌نهایت توکن بسازه و رقیقت کنه.
- **تمرکز هولدرها**: درصد بزرگ‌ترین هولدر و ۱۰ تای اول (نهنگ‌ها می‌تونن با یه فروش نابودش کنن).
- **تشخیص bundle/sniper**: چند کیف‌پول که تو همون ثانیه‌های اول لانچ خریدن = اینسایدرهای هماهنگ.
- **نقدینگی و حجم**: نقدینگی خیلی کم = اسلیپیج بالا و دستکاری راحت.

### ۲) ردگیری Smart Money — `src/analysis/smartMoney.ts`
- لیست کیف‌پول‌هایی که **سابقاً سود واقعی** کردن نگه می‌داره.
- وقتی یکی‌شون می‌خره → سیگنال قوی. وقتی می‌فروشه → **هشدار خروج**.
- کیف‌پول **سازنده‌ی توکن** هیچ‌وقت به‌عنوان smart money برچسب نمی‌خوره (تفکیک تریدر واقعی از کلاهبردار سازنده).

### ۳) موتور امتیازدهی و سیگنال — `src/analysis/score.ts` + `src/signals/strategy.ts`
- امتیاز ۰ تا ۱۰۰ + verdict: `AVOID / RISKY / WATCH / SIGNAL / STRONG_SIGNAL`.
- نقطه ورود + سایز پیشنهادی پوزیشن.
- **پلکان خروج (take-profit)**: مثلاً 2x بفروش ۳۵٪، 3x بفروش ۲۵٪، 5x بفروش ۲۰٪، 10x بفروش ۱۰٪، بقیه با تریلینگ.
- **استاپ‌لاس + تریلینگ‌استاپ** و **تریگرهای خروج پویا** (فروش smart money، افت ناگهانی نقدینگی، فروش نهنگ و…).

### ۴) رابط‌ها
- **بات تلگرام** (`src/telegram/`): پوش سیگنال + دستورهای `/check`، `/recent`، `/signals`، `/addwallet` و…
- **داشبورد وب** (`src/web/`): فید زنده با SSE، جدول توکن‌ها، پنل جزئیات، لینک مستقیم ترید.

## 🇮🇷 نکات مخصوص ایران (مهم)

1. **APIها ایران رو بلاک می‌کنن**: DexScreener، pump.fun و RPCهای سولانا (به‌خاطر تحریم) معمولاً IP ایران رو ۴۰۳ می‌دن.
   👉 **راه‌حل: ربات رو روی یک VPS خارج از ایران اجرا کن** (مثلاً آلمان/فنلاند). نه روی کامپیوتر خودت.
2. **تلگرام**: داخل ایران با پروکسی/MTProto کار می‌کنه، پس سیگنال‌ها بهت می‌رسن. رابط اصلی همینه.
3. **داشبورد**: روی همون VPS بالا میاد؛ از ایران با پروکسی/VPN بازش کن (`WEB_HOST=0.0.0.0` بذار).
4. **ترید کردن میم‌کوین جدید در ایران (بدون KYC)**:
   - یه کیف‌پول **self-custody** بساز: **Phantom** (یا Solflare).
   - با **Jupiter** (`jup.ag`) یا **Raydium** سواپ کن — غیرمتمرکز، بدون احراز هویت، از هر کجا.
   - برای توکن‌های روی منحنی pump.fun، مستقیم تو خود **pump.fun** بخر/بفروش.
   - دکمه‌ی «Trade on Jupiter» و لینک pump.fun تو هر سیگنال هست.
   - SOL اولیه رو از صرافی‌های ایرانی که سولانا دارن یا P2P تهیه کن و به کیف‌پولت بفرست.

## نصب و راه‌اندازی

```bash
# ۱) وابستگی‌ها
npm install

# ۲) تنظیمات
cp .env.example .env
#   حالا .env رو پر کن: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_IDS, SOLANA_RPC_URL

# ۳) اجرا (دِو)
npm run dev
#   داشبورد: http://127.0.0.1:8787

# ۴) اجرای production
npm run build && npm run serve

# تست یک توکن مشخص بدون اجرای کل ربات:
npm run scan -- <mint-address>
```

### کلیدهایی که لازم داری
- **TELEGRAM_BOT_TOKEN**: از [@BotFather](https://t.me/BotFather) بساز.
- **TELEGRAM_CHAT_IDS**: chat id خودت (از [@userinfobot](https://t.me/userinfobot)).
- **SOLANA_RPC_URL**: RPC عمومی خیلی محدوده. یه کلید **رایگان** از [Helius](https://helius.dev) یا QuickNode بگیر و URL کاملش رو بذار. (کیفیت سیگنال‌ها مستقیم به کیفیت RPC بستگی داره.)

### دستورهای تلگرام
```
/check <mint>          آنالیز کامل امنیت + فرصت یک توکن
/recent                آخرین توکن‌های آنالیزشده
/signals               سیگنال‌هایی که از آستانه رد شدن
/wallets               لیست کیف‌پول‌های smart money
/addwallet <addr> [نام]  ردگیری یک تریدر برنده
/delwallet <addr>      حذف یک کیف‌پول
/help                  نکات ریسک و استفاده
```

## معماری

```
PumpPortal (وب‌سوکت لحظه‌ای) ─┐
DexScreener (داده‌ی بازار)   ─┼─▶ Engine ─▶ Score ─▶ Strategy ─┬─▶ Telegram
Solana RPC (mint/holders)   ─┘     (orchestrator)              ├─▶ Web Dashboard (SSE)
                                                               └─▶ Store (JSON)
```

| پوشه | کارش |
|---|---|
| `src/sources/` | منابع داده: `pumpportal` (لحظه‌ای)، `dexscreener` (بازار)، `solanaRpc` (آن‌چین) |
| `src/analysis/` | `score` (امتیاز/verdict)، `bundle` (اینسایدر)، `smartMoney` (ردگیری کیف‌پول) |
| `src/signals/` | `strategy` (ورود/خروج/استاپ) |
| `src/telegram/` | بات و فرمت پیام |
| `src/web/` | سرور Express + داشبورد |
| `src/engine.ts` | ارکستریتور که همه‌چیز رو وصل می‌کنه |

برای جزئیات منطق ورود/خروج و ریسک: [`docs/STRATEGY.md`](docs/STRATEGY.md).

## تنظیم پارامترها (`.env`)
- `SIGNAL_MIN_SCORE` (پیش‌فرض ۷۰): حداقل امتیاز برای پوش به تلگرام.
- `MIN_LIQUIDITY_USD` (پیش‌فرض ۴۰۰۰): حداقل نقدینگی برای بررسی.
- `SMART_MONEY_WALLETS`: لیست اولیه‌ی کیف‌پول‌های برنده (با کاما جدا کن).

## محدودیت‌ها و کارهای بعدی
- شمارش دقیق تعداد هولدرها و کلاسترینگ کامل کیف‌پول‌ها به یک **indexer** (Helius/Birdeye) نیاز داره؛ فعلاً heuristic است.
- کشف خودکار smart money هرچی ربات بیشتر اجرا بشه دقیق‌تر می‌شه.
- اجرای خودکار معامله عمداً پیاده نشده (مدیریت کلید خصوصی = ریسک امنیتی بالا). فعلاً فقط لینک ترید می‌ده.
