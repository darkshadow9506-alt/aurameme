# استراتژی ورود/خروج و مدیریت ریسک

این سند توضیح می‌ده موتور `src/analysis/score.ts` و `src/signals/strategy.ts` **چطور** تصمیم می‌گیرن.
هیچ‌کدوم از این‌ها تضمین سود نیست؛ این‌ها قوانین مکانیکی برای **کم‌کردن ریسک** و **حذف احساساتِ لحظه‌ی معامله** است.

---

## ۱) فلسفه‌ی امتیازدهی

امتیاز نهایی از دو نیمه ساخته می‌شه:

### الف) امنیت (SAFETY) — دروازه‌بان
این نیمه جلوی تله‌ها رو می‌گیره. **یک پرچم قرمزِ بحرانی، کل verdict رو روی AVOID قفل می‌کنه**، حتی اگه هایپ و مومنتوم عالی باشه:

| پرچم | شدت | چرا |
|---|---|---|
| **Freeze authority فعال** | بحرانی → AVOID | سازنده می‌تونه توکنت رو فریز کنه؛ نتونی بفروشی (honeypot کلاسیک) |
| **بزرگ‌ترین هولدر ≥ ۴۰٪** | بحرانی → AVOID | یک فروش = نابودی قیمت |
| **باندل ≥ ۱۲ خرید هم‌زمان** | بحرانی → AVOID | لانچ کاملاً اینسایدری/sniped |
| **≥ ۸ خریدار اولیه از یک منبع SOL** | بحرانی → AVOID | کلاستر باندلِ هماهنگ (indexer) |
| Mint authority فعال | بالا | رقیق‌سازی نامحدود |
| تمرکز ۱۰ هولدر اول ≥ ۶۰٪ | بالا | فشار فروش اینسایدری |
| کلاستر funder ۴ تا ۷ | بالا | احتمال باندل (indexer) |
| تعداد هولدر < ۱۵ | متوسط | خیلی کم، هماهنگی دامپ راحت |
| نقدینگی < ۲۰۰۰ دلار | متوسط | اسلیپیج و دستکاری |

> **نکته‌ی مهم تمرکز هولدر:** اکانت‌های نقدینگی/منحنی (pump.fun, Raydium, Orca, Jupiter) از محاسبه‌ی «نهنگ» حذف می‌شن، چون اون‌ها نقدینگی‌اند نه ریسک. این کار با کلید Helius انجام می‌شه؛ بدون اون، روی تخمینِ RPC کار می‌کنه.

### ب) فرصت (OPPORTUNITY) — فقط وقتی امنیت پاس شد مهمه
- نقدینگی سالم (نه خیلی کم، نه پوچ)
- نسبت **حجم/نقدینگی** (نشانه‌ی فعالیت واقعی)
- نسبت خرید به فروش (فشار خرید)
- روند کوتاه‌مدت سالم (نه از قبل پارابولیک)
- مارکت‌کپ در «ناحیه‌ی شیرین» (به‌اندازه‌ی کافی زود، با نشانه‌ی حیات)
- **خرید smart money = قوی‌ترین سیگنال صعودی**

### ترکیب
```
score = opportunity × (0.4 + 0.6 × safetyFactor)
اگر پرچم بحرانی → score حداکثر ۱۵ (AVOID)
```
یعنی آپساید یک توکن پرریسک، شدید تخفیف می‌خوره.

| امتیاز | verdict | یعنی |
|---|---|---|
| ≥ ۸۲ | 🚀 STRONG_SIGNAL | بهترین حالت: امنیت پاس + مومنتوم + smart money |
| ۶۵–۸۱ | ✅ SIGNAL | ستاپ معتبر |
| ۴۵–۶۴ | 👀 WATCH | منتظر تأیید بمون |
| ۲۵–۴۴ | ⚠️ RISKY | ریسک بالا |
| < ۲۵ یا پرچم بحرانی | 🛑 AVOID | دست نزن |

## ۲) قوانین ورود

| verdict | ورود؟ | حداکثر سایز (از بودجه‌ی قمار میم‌کوین) |
|---|---|---|
| STRONG_SIGNAL | بله | ۸٪ |
| SIGNAL | بله | ۵٪ |
| WATCH | نه (منتظر تأیید) | ۲٪ |
| RISKY / AVOID | نه | ۰ |

قوانین:
- **پله‌ای وارد شو**: نصف الان، نصف روی retestِ یک کفِ بالاتر. هیچ‌وقت کل سایز رو وسط یک کندل سبز مارکت‌بای نکن.
- اگه نقدینگی < ۱۰هزار دلاره: سایز کوچیک، اسلیپیج ۸–۱۵٪.
- «درصد سایز» فقط از **بودجه‌ی میم‌کوینِ** توئه — و اون بودجه باید پولی باشه که ۱۰۰٪ از دستش بدی مشکلی پیش نیاد.

## ۳) قوانین خروج (مهم‌ترین بخش برای «قبل دامپ بیرون بیا»)

### پلکان برداشت سود (Take-Profit)
هدف: **سرمایه‌ی اولیه رو زود برگردون**، بعد بقیه رو سواری بگیر.

| قیمت | بفروش |
|---|---|
| 2x | ۳۵٪ (تقریباً کل هزینه‌ت برمی‌گرده) |
| 3x | ۲۵٪ |
| 5x | ۲۰٪ |
| 10x | ۱۰٪ |
| باقیمانده ~۱۰٪ | فقط با تریلینگ‌استاپ |

### استاپ و تریلینگ
- **استاپ‌لاس**: ۳۰–۴۰٪ (هرچی verdict قوی‌تر، استاپ کمی بازتر).
- **تریلینگ‌استاپ**: وقتی تو سود رفتی، اگه قیمت ۳۵٪ از **سقفش** افت کرد، خارج شو.

### تریگرهای خروج پویا (محافظ ضدِ دامپ)
این‌ها چیزی‌ان که تلاش می‌کنن **قبل از دامپ سنگین** بیرونت بکشن:
1. **smart money شروع به فروش کرد → فوراً خارج شو**، منتظر چارت نمون.
2. نقدینگی ناگهان > ۳۰٪ افت کرد → احتمال کشیدن نقدینگی (rug) → همین الان بفروش.
3. کیف‌پول نهنگ/سازنده انتقال یا فروش بزرگ زد → خارج شو.
4. بعد از یک اسپایک، نسبت خرید/فروش برگشت و حجم خوابید → سود بگیر.
5. freeze authority ظاهر شد یا mint authority استفاده شد → آنی بفروش.

> **چرا تضمین نیست:** دامپ می‌تونه در یک کندل اتفاق بیفته و نقدینگی آنی کشیده بشه. این قوانین احتمال خروجِ به‌موقع رو بالا می‌برن، ولی هیچ سیستمی نمی‌تونه همیشه قبل از همه بفروشه. به همین خاطر پله‌ی 2x (برگشت سرمایه) از همه مهم‌تره.

## ۴) تشخیص تریدر واقعی از سازندهٔ کلاهبردار

- **سازنده/دِو**: همون کیف‌پولیه که توکن رو `create` کرده و معمولاً تو لانچ می‌فروشه. این هیچ‌وقت به‌عنوان smart money برچسب نمی‌خوره (`noteCreator` بلاکش می‌کنه).
- **تریدر واقعی برنده**: کسیه که **بعدِ** ساخت، روی **چندین توکن مختلف**، با **PnL مثبت تحقق‌یافته** خریده و فروخته و سازنده نیست. این‌ها به جدول smart money اضافه/ترفیع می‌شن (`recordRoundTrip`).

هرچی ربات بیشتر اجرا بشه، این جدول دقیق‌تر می‌شه. می‌تونی کیف‌پول‌های برنده‌ی شناخته‌شده رو هم دستی با `/addwallet` اضافه کنی تا از همون اول ردگیری بشن.
